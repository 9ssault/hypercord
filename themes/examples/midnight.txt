// A theme is data, not code. These are the ten colour tokens themes/index.js

// theme that declares one is refused before it is installed, because themes have no
// hooks and no remote assets. Applying a theme goes through the pinned runtime's
// semantic-colour updater, which is why each value becomes a triple - the same
// colour for normal, dark and high-contrast - and why a token this client does not
// know would be a silent no-op rather than an error on Discord's screen.

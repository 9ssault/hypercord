# Native dependency provenance

Assault's manager directly calls `ApkPatcher` from JingMatrix/LSPatch v1.2. The release JAR is fetched at build time and pinned by SHA-256. Its Java classes and opaque injection assets are separated before R8; the original `ApkPatcher.class` is excluded and replaced with the corresponding GPL-3.0 source in `manager/src/main/java/org/lsposed/patch/ApkPatcher.java`. Obtain its corresponding source at https://github.com/JingMatrix/LSPatch/tree/v1.2 (including its documented submodules). The distribution includes native runtime binaries inside the JAR. The vendored `ApkPatcher` has scoped changes: align native libraries and the nested original APK to 16 KB (upstream: 4 KB), and insert self-contained compiled launcher XML before linking and signing (XML aligned to 4 bytes). Split identity is read from manifest metadata. Code-less bases get a correctly named bootstrap DEX and hasCode=true. Split manifests also receive any explicit version-code override so the set stays installable; loader injection remains limited to the base. Uncompressed original native libraries must already be 16 KB-aligned; incompatible inputs are rejected to avoid duplicating libraries or silently retaining an incompatible nested original. The nested original remains unchanged. This avoids repacking linked entries or duplicating Discord's content. `NativePatcher` delegates to this source implementation; there is no reflective access to patcher internals. Keep this adaptation when updating the pinned dependency. R8 retains Gson's external patch-config field names, APK signing's reflective ASN.1 data/annotations and the Xposed entry points. No injected LSPatch runtime asset is rewritten. Unused Maven metadata, optional Java SE provider registration and certificate-review message catalogs are excluded from Manager packaging. License notices are retained.

Revenge v1.11.6 is downloaded and checksum-verified unchanged as the build input `src/main/assets/revenge.js`. The loader Gradle `runtimeAssets` task changes selected display labels to Assault and packages a single `assets/assault-runtime.js`; runtime functions, module names, network URLs and plugin/theme APIs are preserved. These branding substitutions are maintained in `loader/build.gradle`. Its corresponding source is https://github.com/revenge-mod/revenge-bundle/tree/v1.11.6. The Assault loader uses the public Xposed API to inject it into Discord's React Native script loader. Hook class names are version-dependent.

The Xposed API dependency is compile-only; no Xposed API implementation is bundled in the Assault loader.

Retain `licenses/` with redistributed builds. Manager source is GPL-3.0; the Revenge runtime, including its display-branding adaptation, remains BSD-3-Clause. All modifications specific to Assault are present in this repository. The download portal remains separate from the Android program.

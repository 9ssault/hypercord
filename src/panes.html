Access keys

    

      A key is a Discord account token. It is encrypted on this machine with the OS keyring, never written in
      clear, never logged, and never shown again once it is saved — only its last four characters and a
      fingerprint are. A stored key is what lets this client sign in as that account instead of stopping at
      Discord’s login page.
